# Duycuong

## namco_member_edit.py

Mở trình duyệt, chờ bạn đăng nhập NAMCO bằng tay, rồi điền sẵn 姓 / 名 / セイ / メイ
trên trang `member_edit.html`. Script **không** tự bấm lưu.

```bash
pip install -r requirements.txt
playwright install chromium
python namco_member_edit.py
```

Sửa giá trị cần điền trong danh sách `FIELDS` ở đầu file.
