# Duycuong — Học code từ đầu

Nơi lưu các bài học lập trình (Python, HTML/CSS/JavaScript), mỗi bài một thư mục.

## Cách chạy một bài

```bash
python3 bai-01-lam-quen/xin_chao.py
```

Bài web (HTML): bấm đúp vào file `index.html` để mở bằng trình duyệt.

## Danh sách bài học

| Bài | Nội dung |
|-----|----------|
| [Bài 1 — Làm quen](bai-01-lam-quen/) | `print`, biến, phép tính, `if/else`, vòng lặp `for` |
| [Bài 2 — Trang web đầu tiên](bai-02-trang-web/) | HTML, CSS, JavaScript: nút bấm, ô nhập, sự kiện |

Mỗi bài có:
- `xin_chao.py` (hoặc file ví dụ): đọc từng dòng, chạy thử, rồi sửa để xem điều gì thay đổi.
- `bai_tap.py`: bài tập để bạn tự làm.
