# Duycuong — Học code từ đầu

Nơi lưu các bài học lập trình (Python), mỗi bài một thư mục.

## Cách chạy một bài

```bash
python3 bai-01-lam-quen/xin_chao.py
```

## Danh sách bài học

| Bài | Nội dung |
|-----|----------|
| [Bài 1 — Làm quen](bai-01-lam-quen/) | `print`, biến, phép tính, `if/else`, vòng lặp `for` |

Mỗi bài có:
- `xin_chao.py` (hoặc file ví dụ): đọc từng dòng, chạy thử, rồi sửa để xem điều gì thay đổi.
- `bai_tap.py`: bài tập để bạn tự làm.
